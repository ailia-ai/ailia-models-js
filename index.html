ailia.js Demo

Run AI inference directly in your browser with WebAssembly.

About

ailia.js is the JavaScript version of the ailia SDK. It runs neural networks entirely inside the browser using WebAssembly, so no server-side inference and no data upload are required. Pick a model below to try it: the vision models run on a sample image or your camera, and Silero VAD on a sample clip or your microphone.

Available models

Blaze Face Face detection FaceMesh-V2 478 point face mesh Blaze Hand Hand landmark detection U²-Net Background removal MobileNet SSD Object detection YOLOX Tiny Object detection Silero VAD Voice activity detection
