ailia.js Demo

Run AI inference directly in your browser with WebAssembly.

About

ailia.js is the JavaScript version of the ailia SDK. It runs neural networks entirely inside the browser using WebAssembly, so no server-side inference and no data upload are required. Pick a model below to try it with a sample image or your camera.

Available models

Blaze Face Face detection Blaze Hand Hand landmark detection MobileNet SSD Object detection YOLOX Tiny Object detection
